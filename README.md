## 🚀 GitHub Pages पर 1 मिनट में लाइव कैसे करें (How to Deploy to GitHub Pages)

इस रिपॉजिटरी में **`index.html`** पूरी तरह से सेल्फ-कंटेन्ड (Standalone Ready-to-Use) है। इसमें किसी भी जटिल बिल्ड स्टेप या सर्वर की आवश्यकता नहीं है!

1. इस पूरे प्रोजेक्ट को अपने GitHub Repository में पुश (Push) या अपलोड करें।
2. GitHub Repository के **Settings** टैब पर जाएं।
3. बाएँ मेन्यू (Left Menu) में **Pages** विकल्प पर क्लिक करें।
4. **Build and deployment** के तहत:
   - **Source:** Deploy from a branch
   - **Branch:** `main` (या `master`)
   - **Folder:** `/ (root)`
   - **Save** पर क्लिक करें।
5. 1 मिनट के अंदर आपकी वेबसाइट लाइव हो जाएगी:
   👉 `https://<your-username>.github.io/<repository-name>/`

## ✨ मुख्य सुविधाएं (Key Features Included)

1. **एनिमेटेड स्प्लैश स्क्रीन (Splash Screen):**
   - 🌾 किसानकनेक्ट ब्रांडिंग, प्रगति लोडर, स्किप बटन और संस्थापक **हेमांग चौधरी (Hemang Choudhary)** का क्रेडिट।

2. **लॉगिन पेज (Dedicated Login Window):**
   - **Buyer (ग्राहक)** और **Farmer (किसान)** के लिए अलग-अलग कार्ड्स।
   - **"बिना लॉगिन अतिथि के रूप में जारी रखें (Continue as Guest)"** का सीधा 1-क्लिक बटन।
   - 1-क्लिक **Demo Buyer** और **Demo Farmer** क्रेडेंशियल्स।

3. **दो अलग-अलग विंडोज़ (Separate Windows):**
   - **Buyer Window (ग्राहक मंडी):** 
     - लाइव एपीएमसी मंडी भाव टिकर (सीहोर, खन्ना, अलवर, लासलगांव, कोलार)।
     - ताज़ा फसलें (गेहूं, बासमती धान, टमाटर, शुद्ध गीर गाय का बिलोना घी, कश्मीरी सेब)।
     - किसान से डायरेक्ट चैट व भाव तोल-मोल (Bargain Tool)।
     - 5-चरणों में लाइव GPS ऑर्डर ट्रैकिंग (OTP सत्यापन के साथ)।
     - डिजिटल कार्ट और चेकआउट पर कन्फेटी सेलिब्रेशन।
     - दोतरफा रेटिंग व समीक्षा प्रणाली (5 स्टार्स)।
     - अक्सर पूछे जाने वाले प्रश्न (FAQ)।
   - **Seller Window (किसान पोर्टल):**
     - 4 बड़े टच मेट्रिक्स (कुल बैंक भुगतान ₹52,000, 4 सक्रिय फसलें, 2 पेंडिंग ऑर्डर्स, 4.9 किसान रेटिंग)।
     - अपनी लिस्टेड फसलें और 0% कट गारंटी।
     - **+ नई फसल लिस्ट करें (Add Harvest)** का फॉर्म।
